# Calendar

Today and tomorrow from Teams, Mac, Slack, or Google Calendar. Ships a calendar widget for the layout.

This app ships **built into GlanceThing** as `calendar`. Installing this zip warns **Reserved App ID**.

GlanceThing-native.

## Layout

```
calendar/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `calendar-app-v1.0.0.zip`.
