# Example App

A template you can copy to make a new GlanceThing app.

Copy this folder to start a new community app. Change `id` in `manifest.json` before you publish.

Official GlanceThing template.

## Layout

```
exampleapp/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `exampleapp-app-v1.0.0.zip`.
