# GitHub

Your repos, stars, pull requests and issues.

This app ships **built into GlanceThing** as `github`. Installing this zip warns **Reserved App ID**.

Inspired by dakota-kallas/DeskThing-GitHub. GlanceThing-native source.

## Layout

```
github/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `github-app-v1.0.0.zip`.
