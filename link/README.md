# Link

Shared tap board between connected Car Things.

This app ships **built into GlanceThing** as `link`. Installing this zip warns **Reserved App ID**.

Inspired by ItsRiprod/Deskthing-Apps link. GlanceThing-native source.

## Layout

```
link/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `link-app-v1.0.0.zip`.
