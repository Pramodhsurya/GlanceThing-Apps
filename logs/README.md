# Console Logs

Live GlanceThing logs.

This app ships **built into GlanceThing** as `logs`. Installing this zip warns **Reserved App ID**.

Inspired by ItsRiprod/Deskthing-Apps logs. GlanceThing-native source.

## Layout

```
logs/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `logs-app-v1.0.0.zip`.
