# Mic

Pick which mics to control. Tap to mute or unmute. Optional pop-up when a mic is in use.

This app ships **built into GlanceThing** as `mic`. Installing this zip warns **Reserved App ID**.

GlanceThing-native.

## Layout

```
mic/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `mic-app-v1.0.0.zip`.
