# Music

Now playing with seek, skip 10 seconds, shuffle, repeat and volume.

This app ships **built into GlanceThing** as `music`. Installing this zip warns **Reserved App ID**.

Inspired by DeskThing-GMP and DeskThing Local Audio. GlanceThing-native source.

## Layout

```
music/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `music-app-v1.0.0.zip`.
