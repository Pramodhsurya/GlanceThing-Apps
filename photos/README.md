# Photos

Browse the photo album from the tray. Ships a photo widget for home pages.

This app ships **built into GlanceThing** as `photos`. Installing this zip warns **Reserved App ID**.

GlanceThing-native.

## Layout

```
photos/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `photos-app-v1.0.0.zip`.
