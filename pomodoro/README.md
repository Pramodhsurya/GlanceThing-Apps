# Pomodoro

Focus timer with short and long breaks.

This app ships **built into GlanceThing** as `pomodoro`. Installing this zip warns **Reserved App ID**.

Inspired by grahamplace/pomodoro-thing. GlanceThing-native source.

## Layout

```
pomodoro/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `pomodoro-app-v1.0.0.zip`.
