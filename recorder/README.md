# Recording Notes

Record voice notes with the Car Thing's microphone.

This app ships **built into GlanceThing** as `recorder`. Installing this zip warns **Reserved App ID**.

Inspired by ItsRiprod/Deskthing-Apps recorder. GlanceThing-native source.

## Layout

```
recorder/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `recorder-app-v1.0.0.zip`.
