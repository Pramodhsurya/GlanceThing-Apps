# Resource Usage

CPU, memory and uptime of this computer.

This app ships **built into GlanceThing** as `system`. Installing this zip warns **Reserved App ID**.

Inspired by ItsRiprod/Deskthing-Apps system. GlanceThing-native source.

## Layout

```
system/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `system-app-v1.0.0.zip`.
