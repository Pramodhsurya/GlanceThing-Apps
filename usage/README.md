# AI usage

Codex, Claude and Cursor limits and spend, with widgets you drop on a page.

This app ships **built into GlanceThing** as `usage`. Installing this zip warns **Reserved App ID**.

GlanceThing-native. Follows the approach of CodexBar.

## Layout

```
usage/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `usage-app-v1.0.0.zip`.
