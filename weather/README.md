# Weather

Fullscreen 10-day forecast from the tray, plus a weather widget for home pages.

This app ships **built into GlanceThing** as `weather`. Installing this zip warns **Reserved App ID**.

GlanceThing-native. Weather, calendar, AI usage and photos are home features that also ship as tray apps.

## Layout

```
weather/
├── manifest.json
├── src/                 # GlanceThing React source (reference)
└── client/              # Packaged web UI GlanceThing serves
    ├── index.html
    ├── app.js
    └── app.css
```

## Install

GlanceThing → **Apps** → **Add App** → `Pramodhsurya/GlanceThing-Apps`, or upload `weather-app-v1.0.0.zip`.
